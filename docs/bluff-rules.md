# 唬牌(Bluff / 吹牛)规则定稿

> 5 人以下的小局玩法,和炸金花共用同一套设施(RNG / 回放 / 隐私视图 / LLM 席位 / 擂台)。
> 本文是**规则唯一来源**:代码里改规则必须同步这里,测试(SBLUFF-xx)钉住每一条。

## 一、牌与人数

| 项 | 值 |
|---|---|
| 牌 | 104 张(13 点数 × 8 花色) |
| 人数 | 4 人 |
| 手牌 | 每人 26 张(**全部发完**,场上未知集合完全闭合 → AI 可精确计算) |
| 先手 | **庄家先手**,每局换庄 |
| 一盘 | 4 局(每人坐庄一次) |

## 二、一局的流程

```
1. 开局:随机指定 1 个点数当【癞子】(公开;**每局重抽**)
2. 回合:抽 1 个【非癞子】点数 R(公开;**每回合重抽**)
3. 出牌者二选一:
     · 出牌:从手里挑 **1~5 张**扣着放上桌,宣告「这几张都是 R」
       —— **不能过牌**(没有出 0 张这个选项)
     · 质疑:只针对**上一手**(只有下家能质疑)
4. 质疑结算:
     · 上一手**全是 R 或癞子** → 质疑失败 → **质疑者吃下整堆**
     · 上一手有任意一张不是 → 质疑成功 → **出牌者收回整堆**
5. **无论质疑成败,接下来都是下家出牌** → 1→2→3→4 循环永不破
   (这一条堵死了「靠质疑逃一手」的漏洞)
6. 结束:有人**出空手牌** ✓ 或 有人手牌 **超过爆牌线** ✗
```

## 二·补、抽点数的两种方式

| 模式 | 规则 | 体感 |
|---|---|---|
| `one` | 每回合随机抽 **1 个**非癞子点数 | 运气成分大:手里只有 1~2 张能诚实出,想出 3~5 张就得撒谎 |
| `choose3` | 每回合抽 **3 个**,由出牌者**选 1 个**宣告 | 把"祈祷"变成"选择":界面会显示每个候选"我有几张真的" ✓ |

实测(四人真实性格 · 60 盘 · 自适应 AI):

| 抽点数 | 爆牌线 | 动作/局 | 质疑/局 | 出空:爆 |
|---|---|---|---|---|
| one | 40 | 25.3 | 2.5 | 117:123 |
| one | **52** | 43.5 | 7.1 | **180:60** ✓ 最舒服 |
| choose3 | 40 | 28.8 | 8.4 | 41:199 ✗ 容易爆 |
| **choose3** | **52** | 62.7 | **22.1** | 111:129 ✓ 最热闹 |

**推荐**:怕爆就 `one + 52` ✓;想有主动权就 `choose3 + 52` ✓

## 三、局末结算(零和)

```
mean = 四人剩牌数的平均值
每人得分 = round((mean − 自己剩牌数) × 倍率)
四舍五入的漂移补给分数最高的那家 → 严格零和
```

**牌堆不计分** ✓:局末桌上剩的牌**不进任何人的手牌、不参与结算**,只做**日志展览** ✓

## 四、爆牌线:两种模式可选

| 模式 | 阈值 | 手感 |
|---|---|---|
| `tight` | **40** 张 | 更刺激:吃一次大牌堆就爆,爆牌局多 |
| `loose` | **52** 张(= 两副手牌量)| 更技术:给「抢先出空」留出空间,出空赢更多 |

两者都跑得通,由玩法/界面选择(代码里:`BLUFF_BUST_MODES`)✓

## 五、局末展览(信誉系统)

局末把账翻开 ✓:

* **牌堆真容**:这局堆了多少张、各点数实际几张
* **谎话账本**:每人报了几手、出了几张、其中**几张是假的**、最大的一谎几张
* **牌堆去向**:哪几次质疑、谁吃掉了多少张 ✓(局末牌堆常为空 —— 最后那次质疑把整堆吃走了,这里就是要解释它去了哪 ✓)
* **逐手回顾**:整局每一手报了几张、其中几张是真的 ✓(局末才公开)
* **纯日志**:不计分、不影响任何人 ✓

**它的作用不只是好看** ✓:整局的谎话变成**公开记录** → 一个长期撒谎的对手会被读死 ✓
→ 于是理性打法必须把撒谎率压在一个稳定水平 → **质疑机制自然复活** ✓
(实测:自适应 AI 用这份账本学习后,赌徒的夺冠率从 89% 掉到 21% ✓)

## 六、AI

| 档 | 做法 |
|---|---|
| 随机 | 基线 |
| **结构精确型** | 超几何算 P(他报的 k 张全是 R 或癞子) |
| **自适应** | 用局末账本在线估计每个对手的撒谎率,Beta-Binomial 与结构模型融合 |

**关键教训**(实现时踩过的坑):

1. 不能算 P(随机 k 张全真)✗ —— 要算 **P(诚实 | 他选择报 k 张)**(选择效应)。
   漏了这一层 → 逢报必疑 → 镜像局 250~34000 动作/局。
2. 学习要够快。α=6 时赌徒仍 60% 夺冠;α=1 时掉到 21% ✓
3. agent 必须**每盘新建**,否则跨盘串数据、学到非平稳分布。

## 七、风格(从炸金花沿用「形状」,但轴不同)

| 轴 | 说明 |
|---|---|
| 质疑门槛 | 多疑 vs 轻信 |
| 贪心撒谎 | 明明能诚实,偏要多报 |
| 谎报尺寸 | 一张假牌都没有时敢报几张 |
| 爆牌恐惧 | 吃下去会爆时,是否更谨慎 |

### 四位 AI 的名字(作者命名)

| 名字 | 性格 | 参数要点 |
|---|---|---|
| **Lao6**(老六) | 赌徒:偷鸡阴人 | 敢谎报 5 张、敢质疑、不怕爆 |
| **Bajiao**(芭蕉) | 标准 | 按概率办事,偶尔贪一点 |
| **Nizi**(妮子) | 多疑但不贪 | 爱管闲事、动不动要看牌 |
| **Nannan**(囡囡) | 老实人 | 几乎不质疑、从不说谎 —— 最好骗的那位 |
| **Lynn** | **自进化** | 读对手(局末账本)+ 调自己(每盘对 5 个参数做留优弃劣的 (1+1)-ES) |

**锦标赛实测(200 盘 × 4 局,座位轮换,爆牌线 52 + 抽3选1)**:

| 选手 | 平均每盘 | t 值 | 夺冠率 | 备注 |
|---|---|---|---|---|
| **Lynn** | **+44.6** | **26.87** | 56% | 顶替 Lao6 的位置(同对手同种子) |
| Nizi | +24.6 | 12.35 | 69% | 固定性格里最强:多疑 |
| Nannan | +16.8 | 11.82 | 0% | 波动最小,从不夺冠但稳赚 |
| Bajiao | +13.9 | 7.25 | 12% | 标准 |

* **Lynn 比它顶替的 Lao6 好约 100 分/盘** ✓(同对手、同种子、同轮换 → 可直接比较)
* **性格是相互克制的** ✓:Lao6 能通吃从不质疑的 Nannan,却在多疑的 Nizi 面前垫底 —— 没有绝对强的性格

**注意:风格会跨游戏翻转** ✗ —— 炸金花里激进型垫底,唬牌里「敢撒谎 + 敢质疑」的赌徒在**不学习的对手**面前 89% 通吃 ✓

## 八、测试钉住的规则

| 用例 | 钉住什么 |
|---|---|
| `BLUFF-01` | 4×26 全发、无重复、牌数守恒 |
| `BLUFF-02` | 每回合抽的点数绝不是癞子 |
| `BLUFF-03` | 不能过牌 |
| `BLUFF-04` | 出牌张数必须 1~5 |
| `BLUFF-05` | 质疑判定(含癞子算真话) |
| `BLUFF-06` | 质疑后仍是下家出牌(循环不破) |
| `BLUFF-07` | 出空赢 / 超过爆牌线结束 |
| `BLUFF-08` | 结算零和 |
| `BLUFF-09` | 一整盘能打完 + 全程不变量成立 |
| `BLUFF-10` | 牌堆是叠加的,质疑结算时整堆被吃走并清零 |
| `BLUFF-11` | 局末展览(牌堆真容 + 谎话账本) |
| `BLUFF-12` | 自适应模型会记账、会质疑被证明过的骗子 |
| `BLUFF-13` | 两种爆牌线(40 / 52)各自生效 |
| `BLUFF-14` | 局末牌堆不计分,只做展览 |

## 十一、运行方式

```bash
node web/server.ts                    # 默认 http://127.0.0.1:8787(只绑本机)
node web/server.ts --port=8899        # 换端口
node web/server.ts --host=0.0.0.0      # 开放局域网:手机 / 平板各拿一台玩热座
```

* **一个进程管两个游戏**:炸金花在 `/`,唬牌在 `/bluff`;会话互不影响
* 接口统一在 `/api/bluff/{new,state,action}`(与炸金花的 `/api/*` 同一套命名)
* Key 只从环境变量读:`GLM_API_KEY` / `DS_API_KEY`

## 十、LLM 座位(已接入)

```bash
export GLM_API_KEY=...        # 智谱
export DS_API_KEY=...         # DeepSeek
node web/server.ts            # 打开 http://127.0.0.1:8787/bluff
# 界面上把某个对家选成 GLM / DeepSeek 即可
```

* 复用 `src/ai/remote.ts` 的 `remoteChat`(公用一次调用通道,不重抄 HTTP)
* prompt 里除自己的手牌,还给【对手画像】= 自适应 AI 从局末账本学到的「他报 k 张时诚实率」
* 输出 JSON 后强制校验:非法动作一律拒绝 → 走兜底(铁律:AI 不能产出非法动作)

**实测(DeepSeek + GLM 各占一席,共 12 手)**

| 模型 | 调用 | 兜底 | 平均延迟 | 观察到的行为 |
|---|---|---|---|---|
| DeepSeek | 3 次 | **0** ✓ | 135ms | 会说「先出真牌**积累真实记录/可信度**」✓ 说明信誉机制它读懂了 |
| GLM | 5 次 | **0** ✓ | 3679ms | 反复用「**我的手牌里没有这张 → 他在撒谎**」推理 ✗ 经典谬误(把自己手牌当全桌) |

**这个对照本身就是那个实验的起点** ✓:GLM 的谬误恰好说明「读人」不是无脑推理 ✓
