# 唬牌(Bluff / 吹牛)规则定稿

> 5 人以下的小局玩法,和炸金花共用同一套设施(RNG / 回放 / 隐私视图 / LLM 席位 / 擂台)。
> 本文是**规则唯一来源**:代码里改规则必须同步这里,测试(SBLUFF-xx)钉住每一条。

## 一、牌与人数

| 项 | 值 |
|---|---|
| 牌 | 104 张(13 点数 × 8 花色) |
| 人数 | 4 人 |
| 手牌 | 每人 26 张(**全部发完**,场上未知集合完全闭合 → AI 可精确计算) |
| 先手 | **庄家先手**,每局换庄 |
| 一盘 | 4 局(每人坐庄一次) |

## 二、一局的流程

```
1. 开局:随机指定 1 个点数当【癞子】(公开;**每局重抽**)
2. 回合:抽 1 个【非癞子】点数 R(公开;**每回合重抽**)
3. 出牌者二选一:
     · 出牌:从手里挑 **1~5 张**扣着放上桌,宣告「这几张都是 R」
       —— **不能过牌**(没有出 0 张这个选项)
     · 质疑:只针对**上一手**(只有下家能质疑)
4. 质疑结算:
     · 上一手**全是 R 或癞子** → 质疑失败 → **质疑者吃下整堆**
     · 上一手有任意一张不是 → 质疑成功 → **出牌者收回整堆**
5. **无论质疑成败,接下来都是下家出牌** → 1→2→3→4 循环永不破
   (这一条堵死了「靠质疑逃一手」的漏洞)
6. 结束:有人**出空手牌** ✓ 或 有人手牌 **超过爆牌线** ✗
```

## 二·补、抽点数的两种方式

| 模式 | 规则 | 体感 |
|---|---|---|
| `one` | 每回合随机抽 **1 个**非癞子点数 | 运气成分大:手里只有 1~2 张能诚实出,想出 3~5 张就得撒谎 |
| `choose3` | 每回合抽 **3 个**,由出牌者**选 1 个**宣告 | 把"祈祷"变成"选择":界面会显示每个候选"我有几张真的" ✓ |

实测(四人真实性格 · 60 盘 · 自适应 AI):

| 抽点数 | 爆牌线 | 动作/局 | 质疑/局 | 出空:爆 |
|---|---|---|---|---|
| one | 40 | 25.3 | 2.5 | 117:123 |
| one | **52** | 43.5 | 7.1 | **180:60** ✓ 最舒服 |
| choose3 | 40 | 28.8 | 8.4 | 41:199 ✗ 容易爆 |
| **choose3** | **52** | 62.7 | **22.1** | 111:129 ✓ 最热闹 |

**推荐**:怕爆就 `one + 52` ✓;想有主动权就 `choose3 + 52` ✓

## 二·补2、质疑赌注(可选规则)

`challengeFee`:质疑**失败**者扣这么多分,**转给被质疑者**(保持零和)。默认 0 = 旧行为。

**实测(2v2 矩阵,每对 150 盘,座位轮换)**:

| 对阵 | 无赌注 | 赌注 −5 分 |
|---|---|---|
| Nizi(多疑) vs Lao6(赌徒) | **+36**(t=4.3,显著) | **+0.5**(不显著)← 多疑的优势被打掉了 ✓ |
| Bajiao vs Lao6 | +135 | +136 |
| Nannan vs Lao6 | +133 | +143 |
| Nannan vs Nizi | +80 | +89 |

* **效果正是想要的** ✓:「逢疑必质疑」不再是免费午餐 → 多疑者对上赌徒的优势从显著变成不显著
* **但没救活赌徒** ✗:Lao6 仍被 Bajiao/Nannan 净胜约 140 分(机制:两个赌徒互相抓,老实人捡漏)
* **最强的策略是「诚实 + 只在证据硬时质疑」** ✓✓:新策略 **Xiaozhen(小针,门槛 0.78、不贪)** 在无/有赌注下都**通吃全场**:
  * 克 Lao6 +140(t=29.5)✓ 克 Nizi +73(t=6.7)✓ **克 Nannan +23(t=52.4)**✓✓(优势小但极其稳定)

## 二·补2.4、信息泄露:连"分数实时跳动"也是泄漏(作者指出)

隐藏信息的设计必须**一以贯之** —— 任何**实时变化**的可见量都是在传递信息:

| 泄漏点 ✗ | 为什么 | 修法 ✓ |
|---|---|---|
| 日志写"谁骗过全场" | 等于当场宣布那手是假的 | 盘中日志滤掉该事件,只在局末展览公开 |
| **积分实时跳动** ✗ | 撒谎奖励一加分 → 座位条上的分数立刻变 → **谁刚骗成了**全桌可见 | 奖励改成**私下账本**,**局末**才入分 |

**总原则**:凡是"未被公开的信息"(没被质疑的谎话、私下记账的质疑分),都**不能**在任何实时可见量里留下痕迹 ——
日志不行 ✗、积分不行 ✗、动画/提示也不行 ✓。用例 `BLUFF-26` / `BLUFF-27` 各钉住一条 ✓

## 二·补2.5、关于「记牌器」:不要把答案喂给 LLM(作者指出)

给模型算好"外面还剩几张真话牌 / 各家剩牌 / 对手命中率"再让它决策,等于让它当**我们计算器的前端** ✗
—— 那测的就不是"它会不会读人",而是"它会不会念数" ✓

所以 `buildBluffPrompt` 的这类辅助量默认**关闭**(脚本里 `--assist=1` 才开)✓
**要比较的对象**应该是:纯读人(LLM)vs 纯计算(自适应)vs 两者混合 —— 而不是"给 LLM 装上计算器" ✓

## 二·补3、日志的隐私铁律(踩过的坑)

**盘中日志只能出现「张数」与「宣告的点数」**,绝不能出现真假判断 —— 包括**间接的**:

* ✗ 曾经的写法:"曹操 **骗过全场**(报 5 张,没人质疑)→ 从其他三家各收 3 分"
  → 这一行等于**当场告诉大家"他刚才那手是假的"** ✗,而整个设计的前提是"没被质疑的谎话要藏住"
* ✓ 现在的做法:"骗过全场"只在**局末展览**里公开(每人的次数 ✓);盘中日志一律滤掉该事件
* 用例 `BLUFF-26` 钉住:**盘中日志里不许出现"骗过全场"** ✓

## 三、局末结算(零和)

```
mean = 四人剩牌数的平均值
每人得分 = round((mean − 自己剩牌数) × 倍率)
四舍五入的漂移补给分数最高的那家 → 严格零和
```

**牌堆不计分** ✓:局末桌上剩的牌**不进任何人的手牌、不参与结算**,只做**日志展览** ✓

## 四、爆牌线:两种模式可选

| 模式 | 阈值 | 手感 |
|---|---|---|
| `tight` | **40** 张 | 更刺激:吃一次大牌堆就爆,爆牌局多 |
| `loose` | **52** 张(= 两副手牌量)| 更技术:给「抢先出空」留出空间,出空赢更多 |

两者都跑得通,由玩法/界面选择(代码里:`BLUFF_BUST_MODES`)✓

## 五、局末展览(信誉系统)

局末把账翻开 ✓:

* **牌堆真容**:这局堆了多少张、各点数实际几张
* **谎话账本**:每人报了几手、出了几张、其中**几张是假的**、最大的一谎几张
* **牌堆去向**:哪几次质疑、谁吃掉了多少张 ✓(局末牌堆常为空 —— 最后那次质疑把整堆吃走了,这里就是要解释它去了哪 ✓)
* **逐手回顾**:整局每一手报了几张、其中几张是真的 ✓(局末才公开)
* **纯日志**:不计分、不影响任何人 ✓

**它的作用不只是好看** ✓:整局的谎话变成**公开记录** → 一个长期撒谎的对手会被读死 ✓
→ 于是理性打法必须把撒谎率压在一个稳定水平 → **质疑机制自然复活** ✓
(实测:自适应 AI 用这份账本学习后,赌徒的夺冠率从 89% 掉到 21% ✓)

## 六、AI

| 档 | 做法 |
|---|---|
| 随机 | 基线 |
| **结构精确型** | 超几何算 P(他报的 k 张全是 R 或癞子) |
| **自适应** | 用局末账本在线估计每个对手的撒谎率,Beta-Binomial 与结构模型融合 |

**关键教训**(实现时踩过的坑):

1. 不能算 P(随机 k 张全真)✗ —— 要算 **P(诚实 | 他选择报 k 张)**(选择效应)。
   漏了这一层 → 逢报必疑 → 镜像局 250~34000 动作/局。
2. 学习要够快。α=6 时赌徒仍 60% 夺冠;α=1 时掉到 21% ✓
3. agent 必须**每盘新建**,否则跨盘串数据、学到非平稳分布。

### 结构杠杆:撒谎成功奖励 + AI 读局(★ 这是目前最有效的一对)
